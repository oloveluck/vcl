vcl: the ValueSet Compose Language for Racket🔗

VCL is the compact, URL-embeddable syntax for a ValueSet’s compose: one expression names the codes. This package parses it with a port of the official grammar, compiles an expression to a ValueSet, decompiles a compose back to VCL, and makes a .vcl file a module. All 60 examples on the spec page parse and survive printing and reparsing. Part of the fhir family.

1 Quick start🔗

1. Install. The packages are not on the Racket package server yet; clone the repositories side by side and install from source:

raco pkg install --link --auto fhir/fhir vcl

2. Write an expression, on the command line or in a file:

$ raco vcl '(http://loinc.org)(85354-9;55284-4)'

{"resourceType": "ValueSet",

 "url": "http://fhir.org/VCL?v1=(http://loinc.org)(85354-9;55284-4)",

 "status": "active",

 "compose": {"include": [{"system": "http://loinc.org",

                         "concept": [{"code": "85354-9"}, {"code": "55284-4"}]}]}}

3. Expand it. The terminology service (fhir-tx) recognises the implicit url anywhere a ValueSet url is expected (a binding, $expand, FHIRPath’s %terminologies.expand()) and compiles it on the fly:

raco fhir-tx expand 'http://fhir.org/VCL?v1=(http://loinc.org)(85354-9;55284-4)' --package hl7.fhir.r4.core.tgz

2 Writing VCL🔗

form

  

meaning

B, "B.123"

  

a code (quoted when it has characters a simple code cannot)

a;b

  

either: the union

p=a,q=b

  

both: the intersection (of filters)

x-y

  

x without y (at the top level only)

(http://loinc.org)(a;b)

  

the codes of a system; a version as (http://loinc.org|2.74)

(http://loinc.org)*

  

every code of a system

^http://hl7.org/fhir/ValueSet/payeetype

  

the members of a value set

prop=B

  

a property filter; also prop<<B (is-a), prop<B (descendent-of), prop~<<B (is-not-a), prop>>B (generalizes), prop<!B (child-of), prop!!<B (descendent-leaf)

prop/"A[0-9]*"

  

regex

prop^{a,b}, prop~^{a,b}

  

in, not in (a code list, a value set url, or a filter list)

prop?true

  

exists

{concept<B}.prop

  

of: the property's values over the members (R6)

The spec gives , and ; no precedence: bracket compound members. Spaces are allowed, newlines are not.

#lang vcl

((http://loinc.org)(41995-2;4548-4);(http://snomed.info/sct)concept<<365845005)-((http://loinc.org)76573-5)

3 Using it🔗

3.1 Command line🔗

raco vcl ’<expression>’

  

the ValueSet JSON (implicit url)

raco vcl expression.vcl

  

the same, from a file

raco vcl –decompile valueset.json

  

the VCL of a ValueSet's compose

--format text|json|outcome chooses how an error is reported. Exit codes: 0, 1 on a VCL error, 2 on usage.

3.2 As a module🔗

A .vcl file holds one expression. (require "bp-panels.vcl") gives source (the text), expression (the AST), compose (the ValueSet.compose jsexpr) and valueset (a whole ValueSet under the implicit url). A parse error is a compile error of the requiring program, and requiring the module registers the value set, so bindings and $expand find it by url. racket bp-panels.vcl prints the ValueSet.

(require (only-in "bp-panels.vcl" [valueset bp-panels])
         (only-in fhir/terminology/operations $expand))          ; fhir-tx
(hash-ref ($expand #:valueSet bp-panels) 'expansion)            ; the codes

3.3 From Racket🔗

(require vcl/compile vcl/decompile fhir/result/result)
(ok-value (vcl->valueset "(http://loinc.org)(85354-9;55284-4)"))   ; a ValueSet jsexpr
(ok-value (vcl->compose "(http://loinc.org)(85354-9;55284-4)"))    ; just the compose
(compose->vcl (hash-ref vs 'compose))                              ; back to text

4 In an editor, for an agent🔗

vcl/support is what the family’s language server (fhir-lsp) and MCP server (fhir-mcp) load for VCL: a document’s diagnostics (the one expression compiled to a compose) and the tool vcl_valueset. It is a fhir/lang/support value.

5 Limits🔗

  • What a compose cannot say is an error: an exclusion below the top level, a conjunction with a plain code, value set or * in it, conflicting systems in one conjunction, a bare *.

  • A nested filter list or an of source goes into filter.value as VCL text.

  • When the terminology service expands a VCL value set, the operators >> (generalizes), !!< (descendent-leaf) and of match nothing.

  • Decompiling is lossy: an include with both concepts and filters keeps the concepts; displays, designations and the compose’s inactive and lockedDate are dropped. The implicit url escapes spaces only.

  • The grammar admits a one-code list, {a}, which the official grammar does not.

6 Reference🔗

#lang vcl🔗

 #lang vcl package: vcl

Provides source, expression, compose and valueset, as above.

vcl/parser/parse🔗

 (require vcl/parser/parse) package: vcl

procedure

(parse-vcl src) → result?

  src : string?
(ok ast) or (err invalid-encoding) with a fhir/diagnostic attached (attached-diagnostic), positioned in the expression. Memoized.

The AST is prefab (vcl/parser/ast): vcl-sub (a system applied to an expression), vcl-conj (,), vcl-disj (;), vcl-excl (-), vcl-code, vcl-star, vcl-include (^uri), vcl-filter (property, operator, value), vcl-of, vcl-code-list, vcl-filter-list.

vcl/compile🔗

 (require vcl/compile) package: vcl

procedure

(vcl->compose x) → result?

  x : (or/c string? any/c)
Text or an AST to (ok compose). A disjunction becomes include entries, a conjunction one include’s filters, a top-level - the exclude, a system distributes over its members, ^uri is a valueSet reference. What a compose cannot say is an err, never an exception: an exclusion below the top level, a conjunction of plain codes, a bare *.

procedure

(vcl->valueset src [#:url url #:name name]) → result?

  src : string?
  url : (or/c string? #f) = #f
  name : (or/c string? #f) = #f
An active ValueSet. url defaults to the implicit VCL url of src; name to "VCLExpression".

procedure

(vcl-print ast) → string?

  ast : any/c
Canonical text, compound members bracketed.

vcl/decompile🔗

 (require vcl/decompile) package: vcl

procedure

(compose->vcl compose) → string?

  compose : jsexpr?
A ValueSet.compose as VCL. For compose-expressible expressions, compiling the result gives the compose back.
